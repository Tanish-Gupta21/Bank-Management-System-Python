# Bank-Management-System-Python
This Bank Management System is a Python-based console application that simulates basic banking operations such as account creation, deposit, withdrawal, account update, and deletion. The project uses Object-Oriented Programming (OOPS) and JSON file handling to store and manage user data permanently.

# This project is mainly designed for Python beginners to understand:

- OOPS concepts
- File handling using JSON
- Real-world application logic
- Data persistence without a database

# Purpose of the Project

- Learn how a basic banking system works
- Practice Python OOPS concepts
- Understand CRUD operations (Create, Read, Update, Delete)
- Store and retrieve data using JSON instead of databases
- Build logic for authentication using account number & PIN

# Features

- Create a new bank account
- Secure login using Account Number & PIN
- Deposit money (limit up to ₹10,000)
- Withdraw money with balance check
- View account details
- Update account details (name, email, PIN)
- Delete bank account permanently
- Data stored safely in data.json file

# Technologies Used

- Python 3
- JSON File(File Handling)
- OOPS(Class & Methods)
- Random & String Modules
- Pathlib Module
